plist 查看与编辑器

本站可用

客户发来一个二进制 plist，手上又没有 macOS，装个编辑器只为看一眼很麻烦。这个页面直接在浏览器里解决。

能做什么

  • XML plist 与二进制（bplist）都能打开，二进制自动转换成可编辑的树
  • 树状展开，任意层级直接改值
  • 增删键、增删数组项
  • 导出标准 XML，可直接放回 EFI

怎么用

  1. 拖入 plist 文件，或粘贴 XML 文本
  2. 点开对应节点修改，注意类型（integer 与 string 不能混）
  3. 点「导出 XML」，下载后放回原位置

文件只在浏览器内存里处理，不上传服务器。编辑完仍建议用 ProperTree 复核一次。
