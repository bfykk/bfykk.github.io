ioreg 在线诊断

本站可用

黑苹果最花时间的一步不是装机，是认硬件。客户发一句「我的本子能不能装」，靠猜没用，让他把 ioreg -l 的输出贴进来就行。

这个工具做什么

  • 从 ioreg 文本里提取所有 PCI / USB 设备 ID
  • 内置 5457 条 PCI 设备、43 条 USB 设备的名字库，认不出来的也能报出厂商与型号
  • 62 条黑苹果规则 + 30 条声卡 codec 表，逐条给出「原生免驱 / 要补丁 / 不可用」
  • 顶部直接给结论：无线、显卡、存储、音频分别什么状态，不用自己对着列表判断

怎么用

  1. 在 macOS 终端执行 ioreg -l | tee ~/Desktop/ioreg.txt
  2. 把文件拖进工具页，或直接粘贴内容
  3. 看诊断卡片，点「复制报告」直接发给对方

解析完全在浏览器本地完成，不经过任何服务器。
