boot-args 生成器

本站可用

论坛上抄来的 boot-args 往往只抄了结果，没抄场景。这里按「你要解决什么」来选，顺带把副作用写清楚。

覆盖的参数

  • 52 个参数，按排查 / AMD 显卡 / Intel 核显 / 音频 / 网络 / 蓝牙 / 平台兼容 / 存储 八类分好
  • 每个参数都写清用途、适用平台与副作用，不想要的自己别勾
  • 12 条互斥检查：npci 两个值、darkwake 两种方向、shikigva 多值、-liluoff 与 beta 参数这类会互相打架的组合直接拦下
  • 可搜索：输入「黑屏」「蓝牙」「DRM」就能筛出相关参数

怎么用

  1. 勾选当前要解决的问题，生成一行参数
  2. 填进 NVRAM → Add → 7C436110-AB2A-4BBB-A880-FE41995C9F82 → boot-args
  3. 问题解决后把临时参数删掉，尤其是 -v 与 debug=0x100

工具会自动提示互斥项，比如两个 npci 值不能同时存在。

打开工具 →

← Device Properties全部工具plist 查看与编辑 →

工具只能给方向，具体到你这台机器还得看实际 ioreg 与 EFI。把 机型 / CPU / 网卡 发过来，先判断可行性。
