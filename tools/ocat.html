OCAT（OCAuxiliaryTools）

配置编辑

OpenCore 的图形化配置工具。拖拽增删 kext、调 quirk、一键升级 OC 版本、内置 config 完整性校验，比在 XML 里数括号直观得多。

什么时候用

  • 第一次配 config，不想手改 plist
  • 把旧版本的 config 升级到新版 OC
  • 快速对比两份配置的差异

上手要点

  1. 改完先用自带校验跑一遍，再上机试。
  2. 升级 OC 版本会重置部分 quirk，升级后要逐项复核。
  3. 它只负责编辑，不负责适配 —— 补丁该不该加，还是得看具体硬件。
