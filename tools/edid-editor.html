EDID 编辑器

显示器 / 在线

显示器 EDID 的在线解析与编辑器，本站内嵌运行，源码来自开源项目 thyge/edid-editor（MIT）。EDID 就是显示器递给系统的那一包字节，写清了它是什么厂商、多大、支持哪些分辨率和刷新率、支不支持 HDR。

黑苹果场景里它有三个用处：一是核实显示器到底报了什么时序，排查"系统里选不到想要的分辨率"；二是改 EDID 让系统识别出隐藏的刷新率或色深；三是核对外接屏走的是 HDMI 还是 DP、有没有被转接芯片改过数据。

能干什么

  • 解析基础块（0x00–0x7F）与 CTA-861 / DisplayID 扩展块，精确到每个 bit
  • 查看厂商、产品型号、序列号、生产周期、Preferred Timing
  • 编辑 Established Timings、Standard Timings、详细时序（分辨率 / 刷新率 / 像素时钟）
  • 改完导出新的 EDID 文件，用于 OpenCore 的 EDID 注入或后续处理

上手要点

  1. 先把显示器原始 EDID 导出来备份（Windows 用 Registry 或 CRU，Linux 用 xrandr --verbose），改坏了还能回去。
  2. 改时序时像素时钟、前后沿、同步宽度要成套改，只改分辨率不改时序参数，系统会直接忽略这条记录。
  3. 校验和（checksum）工具会自动重算，但自己手改字节时要留最后一块的校验位。
  4. 注入 EDID 属于系统层改动，先在另一块屏或安全模式下验证，别把唯一显示输出改没了。
所有解析与保存都在浏览器本地完成，EDID 文件不会上传到任何服务器。原作者项目：github.com/thyge/edid-editor
