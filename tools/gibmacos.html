gibMacOS

镜像下载

从 Apple 官方服务器直取 macOS 安装器，不经过任何第三方打包。版本号和 build 号都来自 Apple 的 catalog，下载完可以校验。

什么时候用

  • 需要原版安装器做启动 U 盘
  • 想找特定 build，比如 10.13.6 的某个补丁版
  • 不想碰各种一键装机魔改包

上手要点

  1. Windows 上也能下载，只是组装成安装 App 必须在 macOS 环境里做。
  2. 老版本（10.13–10.15）Apple 已从 catalog 下架，脚本里可能取不到，需要自备原版包。
  3. 下载目录里是分卷 pkg，别手动解压，交给 BuildmacOSInstallApp 处理。
