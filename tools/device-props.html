Device Properties 生成器

本站可用

config.plist 里最容易出错的地方之一就是 DeviceProperties：路径写错、值类型写错、字节序写错，三种都会让注入静默失效。

支持的三类注入

  • 核显：20 条 ig-platform-id 预设，覆盖 Ivy Bridge 到 Comet Lake / Ice Lake，按代际分组
  • device-id：按 ig-platform-id 自动取高 16 位，2 字节小端，字节序不用自己算
  • 声卡：18 条 layout-id 预设，按 ALC256/257、ALC295/294/298、台式机 ALC887/892/897/1200/1220 分组
  • 自定义：data / integer / string / boolean 任意属性，integer 与 data 两种写法同时给

怎么用

  1. 从 ioreg 里复制准确的 PCI 路径（核显 PciRoot(0x0)/Pci(0x2,0x0)，声卡 PciRoot(0x0)/Pci(0x1f,0x3)）
  2. 选目标与取值，点生成
  3. 把片段粘进 ProperTree 的 DeviceProperties → Add，或 OCAT 的设备属性页

工具会同时给出 integer 与 data 两种写法，data 按 Apple 的小端习惯算好 base64，不用自己换算。
