itlwm / AirportItlwm

无线

Intel 无线网卡的开源驱动。itlwm 走"以太网形式"的思路，AirportItlwm 则伪装成原生无线，能用系统自带的 Wi-Fi 菜单。

什么时候用

  • AX200 / AX201 / AX210 / AX211 这类 Intel 卡
  • 笔记本内置无线，不想拆机换博通卡
  • 只需要上网，不强求隔空投送

上手要点

  1. AirportItlwm 必须按系统版本选分支，版本错位就没有 Wi-Fi 图标。
  2. 隔空投送、接力、随航依赖原生卡，这是硬限制。
  3. 蓝牙驱动要配套，蓝牙走 USB 通道，端口映射不对会断。
