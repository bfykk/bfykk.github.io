USB 端口映射生成器

本站可用

蓝牙时好时坏、摄像头认成外接、USB3 只跑 2.0，基本都是端口没有正确映射。这个工具把最容易写错的部分包掉了。

它生成什么

  • 一份完整的 USBPorts.kext Info.plist
  • 14 个常见 XHCI 控制器预设（Intel 3 代到 13 代、ASMedia），不用自己去 ioreg 翻
  • 批量生成端口名：填 HS / SS 数量，自动铺 HS01–HS14、SS01–SS10
  • 每个端口的 UsbConnector（USB2 / USB3 / Type-C / 内建）与 port 小端序号
  • 超过 15 端口自动报警，内建标记一次写对

怎么用

  1. 先从 ioreg 里查到 XHCI 控制器的 PCI ID，填进工具
  2. 按实际端口列清单：HS01,usb2 这样一行一个
  3. 蓝牙、摄像头、读卡器一律标 internal
  4. 下载 Info.plist，放进 EFI/OC/Kexts/USBPorts.kext/Contents/Info.plist，再把 kext 加进 config

超过 15 个端口工具会直接提示，不用等装完才发现掉设备。

打开工具 →

← config.plist 体检全部工具Device Properties →

工具只能给方向，具体到你这台机器还得看实际 ioreg 与 EFI。把 机型 / CPU / 网卡 发过来，先判断可行性。
