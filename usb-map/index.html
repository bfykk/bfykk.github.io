USB 端口映射生成器

macOS 每个控制器只认 15 个端口，多了就随机丢失。这里按你勾选的端口直接产出 USBPorts.kext 的 Info.plist：端口号、连接类型、内建标记一次写对，蓝牙与摄像头也能被正确识别成内建设备。

批量生成端口名： USB2 个 · USB3 个 · 第一个内建
类型写 usb2 / usb3 / typec / internal。内建设备（蓝牙、摄像头、读卡器）必须选 internal，否则唤醒后失效。端口名按 ioreg 里的写法：USB2 端口一般是 HS01–HS14，USB3 是 SS01–SS10。
生成的 kext 只是端口表，实际能不能用还取决控制器路径与 BIOS 里的 XHCI 设置。把 ioreg 发过来，可以直接给你配好的整套 EFI。
