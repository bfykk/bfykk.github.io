config.plist 在线体检

把 OpenCore 的 config.plist 拖进来，当场检查顶层结构、kext 加载顺序、Quirks 冲突、驱动缺失、SMBIOS 与 boot-args。所有解析在浏览器本地完成，文件不会离开这台电脑。

只支持 XML 格式的 plist（ProperTree / OCAT 默认保存就是这个）。如果是二进制 plist，先在 ProperTree 里另存为 XML。检查项参照 OpenCore 官方文档与 ocvalidate 的检查维度重新实现，不能替代对应版本的 ocvalidate。
体检只能发现结构性问题，看不了「这个 Quirk 在你的主板上到底该不该开」。把 config.plist 和 ioreg 一起发过来，可以按机型给你改。
