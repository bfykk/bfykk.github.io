GitHub 上真实存在、README 写得清楚的案例仓库，按平台方向挑的。本站不托管、不二次打包，只做索引；别人的 EFI 里有他自己的三码和机型差异，直接套会出问题，拿来对照参数用。
数据从哪来
平台判断按 OpenCore 官方配置文档（Docs/Configuration.tex）与 Dortania OpenCore Install Guide 的推荐来：SMBIOS 对应机型、Quirks 适用代际、SSDT 该放哪些、ig-platform-id 与 framebuffer 映射。核显支持与否是 macOS 驱动层面的硬事实，不随配置改变。本站实测记录只有 13 代那台荣耀笔记本（i5-13500H）和交付过的 11 代 Z590 台式，其余平台属于按规则推导，遇到魔改 BIOS、非标芯片组、移动端特例，仍需实机验证。
顺带说一句：RapidEFI（JeoJay127/RapidEFI-Tool）是 AGPL-3.0 的桌面工具，规则库和覆盖面比这个页面厚得多。这个页面是照它那种「选硬件 → 出整套配置」的思路自己重做的网页版，规则表按公开文档整理，没有搬它的模板数据；网页也拿不到你的 ACPI 表，所以只给方案，不替你生成成品 EFI。
平台太偏、或者要成品 EFI？把 型号 / CPU / 显卡 / 无线网卡 发过来，先判断可行性再谈方案。
