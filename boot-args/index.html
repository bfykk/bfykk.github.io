boot-args 生成器

勾选你现在要解决的问题，直接得到一行可用的 boot-args。每个参数都标了适用平台与副作用，不用再翻论坛抄别人的字符串。

排查与日志
-v
详细模式，卡住时能看到最后一行停在哪。装好系统就该去掉。
keepsyms=1
内核崩溃时保留符号，配合 -v 能看到具体出错函数，排查 panic 必备。
debug=0x100
禁止自动重启，panic 画面停住方便拍照。会明显拖慢启动。
副作用：崩溃后不会自动恢复，笔记本可能停在黑屏。
-lilubetaall
让 Lilu 及其插件在未适配的新系统版本上也强行加载，新系统刚发布时常用。
副作用：可能引起不稳定，系统适配后应删掉。
显卡与显示
agdpmod=pikera
AMD Navi（RX 5500/5600/5700/6600/6800）黑屏的经典解法。
-wegnoegpu
禁用独显，只留核显输出。笔记本核显直连屏幕时常用。
igfxonln=1
强制核显在线，解决外接屏唤醒后不亮。
-igfxvesa
核显走 VESA 基础输出，先让画面出来，用于判断问题是否在显卡加速。
副作用：没有硬件加速，界面会卡，仅用于排查。
shikigva=80
老平台的 DRM 视频播放修补，Monterey 之前较常用。
音频
alcid=11
临时指定 AppleALC 布局，等价于在 DeviceProperties 里注入 layout-id。用于快速试布局。
注意：两个地方都写且值不同时，以 boot-args 为准，容易混淆。
平台与兼容
npci=0x2000
PCI 配置空间分配问题的经典解法，常见于 AMD 显卡卡 PCI 阶段。
与 npci=0x3000 互斥；BIOS 开了 Above 4G 后通常不再需要。
npci=0x3000
另一种 PCI 修正值，0x2000 无效时试它。
与 npci=0x2000 互斥，只能留一个。
-no_compat_check
跳过机型号兼容性检查，让不受支持的机型能装上新系统。
副作用：系统更新与部分功能可能异常，属于临时手段。
darkwake=0
调整休眠后的唤醒行为，解决「睡了就醒不过来」或「一睡就醒」。
slide=0
固定内核加载偏移，解决 KASLR 相关的随机卡死，老平台偶尔需要。
-xcpm
老 Ivy Bridge / Haswell 平台的电源管理模式，现代平台不需要。
cpus=1
只用一个核心启动，用于判断是否 CPU 电源管理导致的问题。
副作用：性能骤降，仅排查用。
勾选上面的项目后点「生成 boot-args」。
填到哪里：NVRAM → Add → 7C436110-AB2A-4BBB-A880-FE41995C9F82 → boot-args（string 类型）。改完保存，重启生效。清理时把整行清空即可，不要留一个空格。
参数只是症状处理，很多问题根子在 Quirks 或 ACPI。把 EFI 发过来，可以一次把底层配置改对。
