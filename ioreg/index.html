ioreg 在线诊断

把 ioreg -l 的输出整段粘进来，当场列出这台机器的显卡、无线网卡、声卡 codec、蓝牙、触控板、硬盘，逐项标出原生支持 / 要打补丁 / 换硬件。解析全在浏览器里做，一个字都不会上传。

常用取法：ioreg -l 全量；只要设备树 ioreg -p IOService -l；只要 PCI ioreg -p IOService -n IOPCIDevice -r -l。几百 KB 都正常，文件越大识别越准。
诊断结果只是方向判断，具体补丁要结合机型与 BIOS。把 ioreg 和 EFI 一起发过来，可以直接给你落到 config.plist 的方案。
