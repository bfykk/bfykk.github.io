macOS Big Sur 11

11.x约 11 GBIntel经典

Big Sur 11 是黑苹果口碑最稳的几代之一，和 Apple Silicon 首发同代，社区 EFI 存量最大，遇到问题几乎都能找到同机型案例。

适合谁

  • 4–8 代 Intel，H310 / B360 一类老芯片组
  • 追求装完就不用再管的机器
  • 老笔记本，硬件只够跑这一代

安装要点

  1. OC 版本可以放宽，但建议统一到较新的稳定版，别用太早期的 0.6.x。
  2. 核显 HD 530 / 630 直接可用，按机型配 device-id 即可。
  3. 博通无线卡这一代完全免驱，是最省事的选择。
  4. 老主板记得处理好 RTC 与 AWAC 时钟，不然睡眠会立刻醒。

下载

git clone https://github.com/corpnewt/gibMacOS
cd gibMacOS
python gibMacOS.py

选 11.x 下载，约 11 GB。
