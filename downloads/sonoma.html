系统下载/macOS Sonoma 14

macOS Sonoma 14

14.x约 12 GBIntel / AMD兼容好

Sonoma 14 的兼容面比 Sequoia 更宽，很多 8–10 代平台在这一代最舒服，社区 kext 分支也齐全。代价是新系统的一些特性用不上。

适合谁

  • 8–10 代 Intel 平台，核显 UHD 630 一类
  • 博通无线卡用户 —— 这一代起需要 OCLP 打补丁恢复 Wi-Fi
  • 把兼容性放在新功能前面的机器

安装要点

  1. 博通卡从 Sonoma 开始不再免驱，必须走 OpenCore Legacy Patcher 的 root patch。
  2. Intel 核显 8 代以后基本可用，但要按机型配 framebuffer，平台 ID 抄错会黑屏。
  3. AMD RX 400 / 500 系免驱，配合 WhateverGreen 基本不用额外注入。
  4. 老 NVIDIA 从 Mojave 起就没有 Web Driver，Sonoma 上同样只能靠核显或换卡。

下载

git clone https://github.com/corpnewt/gibMacOS
cd gibMacOS
python gibMacOS.py

选 14.x 下载，约 12 GB。安装前把 config 里的 kext 精简一遍，比事后排错省时间。
