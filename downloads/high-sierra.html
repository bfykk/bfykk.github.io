macOS High Sierra 10.13.6

10.13.6约 5 GBIntel最低版

10.13.6 是 NVIDIA Web Driver 最后支持的版本。手里的 GTX 1050 / 1060 / 1080 想用上独显加速，只能停在这一点。它也是整个系列里门槛最低的一代。

适合谁

  • NVIDIA Pascal / Maxwell 用户，必须要独显驱动
  • 2–4 代 Intel 老平台
  • 只需要一个能跑起来的工作环境

安装要点

  1. Web Driver 的版本号必须和系统 build 严格对应，build 差一位就装不上。
  2. 必须关闭 SIP，CsrActiveConfig 设为 0x67 是常见配置。
  3. 老主板用 AptioMemoryFix 或 OsxAptioFix3Drv，选错会卡在 + 号。
  4. 这一代不支持 NVMe 原生启动的部分老硬盘，需要额外的 NVMe 补丁。

下载

Apple 已彻底下架这一代安装器，gibMacOS 的 catalog 里基本取不到。只能通过 App Store 的历史购买记录，或使用你手上保留的原版 dmg / 安装 App。

如果只是为了跑老软件，先确认是不是真的需要 10.13.6 —— 很多场景 10.15 更合适，也没有 Web Driver 的麻烦。
